# Security and disclosure policy

This is a **public educational lab repository**. Never commit passwords, tokens, public-access URLs with embedded credentials, private keys, certificate bundles containing private keys, raw log exports, real user information, IP addresses outside the isolated lab, or complete backups.

The original lab SOP contains illustrative credential values. Treat any value actually used in the lab as compromised if shared externally: rotate it and remove it from screenshots/commit history before public distribution. `.gitignore` does not remove files already tracked by Git.

Please report accidental disclosure privately to the repository owner; do not create an issue containing the secret. Use the repository's GitHub security features where available.
