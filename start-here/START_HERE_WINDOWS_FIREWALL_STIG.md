# Start here — Windows Defender Firewall STIG V2R2

This optional workstream covers the supplied **Microsoft Windows Defender Firewall with Advanced Security STIG, Version 2 Release 2**, manual XCCDF dated November 9, 2023. It applies only when the system owner confirms the benchmark's scope for the authorized endpoint. The supplied overview describes this guidance for systems not capable of using an approved ESS host intrusion prevention firewall; it is used alongside the applicable operating-system STIG.

1. Read the [complete firewall implementation guide](../docs/stig-windows-firewall/IMPLEMENTATION_GUIDE.md).
2. Work through all [21 source checks and fixes](../docs/stig-windows-firewall/rules/all.md) with a STIG Viewer checklist.
3. Protect console access, management connections, DNS, and the existing WINHUNT01-to-Splunk forwarding path before changing settings.
4. Record results privately and use the [pending sanitized evidence template](../evidence/sanitized/windows-firewall-stig-validation.md) only after approval.

This is a manual assessment guide. No settings have been tested or changed, and no compliance or authorization is claimed. Check DISA for a newer applicable release before an official assessment.
