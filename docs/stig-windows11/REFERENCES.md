# Windows 11 STIG references

- **Supplied DISA manual XCCDF:** Microsoft Windows 11 STIG V2R11, benchmark date September 30, 2026; 257 rules. SHA-256 of the supplied XML: `97680465c4cf44a9be234292f8414f0fe8f4ca8ee8915a2e3f23d840684afde6`. This identifies the supplied copy; a hash alone does not authenticate its publisher.
- **Supplied DISA V2R11 overview and revision history:** These explain scope, assessment considerations, and release changes. Keep the actual documents in your authorized assessment location.
- [DISA STIG announcements](https://www.cyber.mil/stigs/stig-announcements): Lists released security guidance and version updates.
- [DISA STIG downloads](https://www.cyber.mil/stigs/downloads/): Provides official STIG packages and current releases.
- [DISA SCAP resources](https://www.cyber.mil/stigs/SCAP): Lists separately distributed automated benchmarks and tools. A manual XCCDF is not an automated scan package.
- [STIG Viewer 3.x User Guide](https://dl.dod.cyber.mil/wp-content/uploads/stigs/pdf/U_STIG_Viewer_3-x_User_Guide_V1R7.pdf): Explains how to import STIGs and maintain checklists.
- [Microsoft Windows 11 security baseline](https://learn.microsoft.com/en-us/windows/security/operating-system-security/device-management/windows-security-configuration-framework/windows-security-baselines): Explains Microsoft security baselines; these do not replace the selected DISA benchmark.
- [Microsoft BitLocker overview](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/): Explains BitLocker deployment and recovery planning.

Review official documentation for the exact Windows release, platform, tooling, and organization. Supplied screenshots, live evidence, hostnames, recovery keys, checklists, and policy exports are not published here.
