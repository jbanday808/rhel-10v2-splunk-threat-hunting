# Screenshot naming standard

Use two-digit (or three-digit for larger sequences) step numbers and short descriptive names:

- `01_VMware_VMnet8_NAT.png`
- `02_RHEL_Network_Configuration.png`
- `03_Splunk_Data_Disk_Mount.png`
- `04_Splunk_Service_Active.png`
- `05_Splunk_Indexes.png`
- `06_Windows_UF_TLS.png`
- `07_Sysmon_Event_Collection.png`
- `08_Splunk_Hunting_Dashboard.png`
- `09_IdM_LDAPS_Validation.png`
- `10_Splunk_Analyst_Role.png`

For each figure, add a **single sentence** stating only the visible result. Before publishing, crop/blur credentials, identifying values, tokens, certificate secrets, unnecessary usernames and any private data. Save final approved PNGs under `docs/images/`.
