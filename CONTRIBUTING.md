# Contributing

1. Open an issue or create a branch for proposed improvements.
2. Keep example configuration portable and use safe placeholders.
3. Run `python3 scripts/validate_project.py` and review the diff before pushing.
4. Include exact observed software versions when making behavior claims.
5. Do not commit raw event exports, personal data or private credentials.
6. Update validation tables only when a test was run and its outcome recorded.
